# 课程地图

## 面向对象

这套教程假设你已经具备成熟的前端工程经验，但对 Python 语言、生态和后端工程思维还不够成体系。

## 推荐学习顺序

1. 模块 1-3：先建立 Python 语言和工程基础
2. 模块 4-7：从“会写”进入“会设计、会组织、会测试”
3. 模块 8-10：进入数据库、FastAPI、认证和接口设计
4. 模块 11-12：完成异步任务、部署和全栈协作闭环

## 推荐节奏

- 每周 8-12 小时
- 每个基础模块 3-5 天
- 每个项目模块 5-7 天
- 整体建议 10-12 周完成一轮

## 课程产物

- 语言基础示例：`examples/`
- 主项目骨架：`projects/task_collab_api/`
- 模块文档：`docs/tutorial/modules/`

## 主项目路线

主项目是一个 `任务/协作系统 API`，分阶段增长：

1. 项目结构和健康检查
2. 任务 CRUD
3. 数据库存储
4. 用户与认证
5. 权限与过滤
6. 异步通知和部署

## 如何使用本教程

- 不要只看代码，先看“为什么这样设计”
- 不要跳过错误示例，它们通常比正确写法更能帮你建立边界感
- 不要跳过测试和验证命令，工程能力来自重复证明，而不是抽象理解
