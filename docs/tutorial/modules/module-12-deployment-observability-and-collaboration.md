# 模块 12：部署、日志与全栈协作闭环

## 学习目标

- 能把项目放进 Docker 并在本地启动
- 理解环境变量、日志和最基础的可观测性
- 形成面向前后端协作的 API 交付意识

## 核心概念

- 部署不是最后一步补一层壳，而是工程设计的一部分
- 配置与代码分离
- 日志和健康检查是最基础的运行时反馈

## 主项目应用

- 为 FastAPI 项目补 Dockerfile
- 提供 `.env.example`
- 增加 `/health` 接口和结构化日志

## 与前端对照

- 类似前端项目里的构建、环境区分和线上排错
- 但后端更关注进程、数据库、消息队列和运行时状态

## 实战任务

- 在本地容器里跑通项目
- 用前端脚本或 Postman 调用接口
- 检查健康检查和日志输出是否符合预期
