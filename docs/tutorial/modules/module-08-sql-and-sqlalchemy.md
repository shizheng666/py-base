# 模块 8：数据库、SQL 与 SQLAlchemy 2.x

## 学习目标

- 建立表、主键、外键、索引和事务的基本认知
- 看懂 SQLAlchemy 2.x 的模型和查询方式
- 理解 ORM 只是抽象，不会替你消灭 SQL 思维

## 核心概念

- 表结构设计会直接决定后端接口是否稳定
- ORM 负责减少样板代码，不负责替你设计业务模型
- 迁移工具用于显式记录数据库演进

## 主项目应用

- 定义 `users` 和 `tasks` 表
- 使用 `Session` 管理数据库交互
- 为后续认证和任务筛选打基础

## 与前端对照

- ORM 查询有点像链式 query builder
- 但 Python 后端更强调事务边界和持久化状态

## 常用库

- `SQLAlchemy 2.x`
- `Alembic`
- `psycopg`

## 实战任务

- 为任务模型加入标题、状态、优先级、创建时间
- 解释 ORM 模型和 API schema 不应该混成一层的原因
