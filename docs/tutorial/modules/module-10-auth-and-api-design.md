# 模块 10：认证、权限与 API 设计

## 学习目标

- 理解 JWT、密码哈希和用户上下文
- 能设计分页、过滤、排序和错误码
- 知道哪些逻辑属于认证，哪些属于业务授权

## 核心概念

- 认证回答“你是谁”
- 授权回答“你能做什么”
- 接口设计要为前端联调和长期维护服务

## 主项目应用

- 增加注册和登录接口
- 在任务接口里加入用户隔离
- 统一错误响应格式

## 与前端对照

- 类似前端里的 token 登录流
- 但后端必须真正校验权限边界，而不仅是隐藏按钮

## 常用库

- JWT 方案
- 密码哈希方案
- `pydantic-settings` 或等价配置方案
