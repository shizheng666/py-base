# 模块 2：核心语法、数据结构与引用语义

## 学习目标

- 熟悉列表、元组、字典、集合、切片、解包、推导式
- 真正理解 Python 的可变对象、不可变对象和引用语义
- 避免默认参数和浅拷贝等常见陷阱

## 核心概念

- 列表可变，元组不可变
- 字典是后端开发中的核心数据结构之一
- 名字绑定到对象，而不是“变量盒子里装值”的简单模型

## 代码分析

本模块的示例在 `examples/module_02_data_model/`。

- `references.py` 展示列表共享引用和安全复制
- `defaults.py` 展示默认参数陷阱和修正写法

阅读时重点看：

- 为什么两个变量会同时看到同一份列表变化
- 为什么 `tags=[]` 是坏味道
- 为什么 `None` 常被用作默认值哨兵

## 与前端对照

- 列表接近 JS 的 `Array`
- 字典接近 JS 的普通对象，但行为更偏“哈希映射”
- Python 没有像 JS 那样的 `undefined`，`None` 更接近显式空值

## 常用库与工具

- `copy`
- `collections`
- `itertools`

- 分别用错误写法和正确写法实现默认参数
- 解释每种写法为什么会产生不同结果
